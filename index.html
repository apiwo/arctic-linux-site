arctic is a linux distribution built from source, pairing a BSD userland (toybox, zsh, doas, netbsd-curses, bmake) with glibc underneath. busybox handles init. packages install through alpm, its own package manager, with per-file verification and one-command rollback built in. installed declaratively: edit a config file, run one command. a musl port exists alongside glibc too — see the docs.

features

  • toybox userland in place of GNU coreutils, zsh as the login shell
  • declarative install and system management — arctic-strap, arctic-rebuild, no menus
  • doas instead of sudo, netbsd-curses instead of ncurses
  • alpm: rollback, -nomod staging, per-file sha256 verification, alt-nonfree counterparts for every proprietary package
  • NVIDIA, AMD, and Intel drivers coexisting through libglvnd
  • boots to a TTY — no display manager, no desktop, install one afterwards with alpm

STATUS: arctic-minimal boots and installs end to end — Limine → kernel → initramfs → busybox init → zsh, with alpm installing from the repository carried on the medium. no desktop image exists yet, by design.

install

# wired is automatic, for wireless:
iwctl station wlan0 connect YOUR-NETWORK

# edit the config, then one command does everything
vi /etc/arctic/install.conf
arctic-strap

set A_DISK=/dev/sdX in the config and that one command partitions, formats, mounts, installs, and wires up the bootloader. leave it commented out for the manual mount-it-yourself path instead. full walkthrough in the docs.

build it yourself

every build runs sandboxed under bubblewrap — the host is mounted read-only, only the build tree and /tmp are writable. that is not a formality: a recipe that forgets DESTDIR once installed glibc straight over a host's /usr/lib. it now just fails with EROFS instead.

build/arctic-sandbox --check
build/build.sh

contribute

500+ packages are defined in a manifest in arctic-linux-ports, with recipes generated from it rather than hand-written. adding a port means adding a line to the manifest, not boilerplate.

pull requests welcome on github.
